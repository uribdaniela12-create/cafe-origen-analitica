# Café Origen - Analítica v0.1

## Descripción

Este proyecto permite analizar las ventas de Café Origen utilizando JavaScript.

El programa trabaja con un arreglo de objetos y utiliza funciones, ciclos y métodos de arreglos para calcular diferentes indicadores.

## Tecnologías

- JavaScript
- Node.js
- Git y GitHub

## Funcionalidades

- Calcular el dinero total vendido.
- Obtener las unidades vendidas.
- Identificar la venta de mayor valor.
- Calcular el ticket promedio.
- Consultar ventas por ciudad.
- Agrupar las unidades por producto.
- Mostrar los tres productos que más dinero generaron.
- Consultar las ventas de una fecha específica.

## Cómo ejecutar

1. Abrir el proyecto en VS Code.
2. Abrir la terminal dentro de la carpeta del proyecto.
3. Ejecutar el siguiente comando:

`node src/reporte.js`

## Versión

v0.1 - Primera versión del motor de analítica de Café Origen.
