# Café Origen - Analítica

Este proyecto tiene como objetivo analizar las ventas
de Café Origen utilizando JavaScript.

## Tecnologías
- JavaScript
- Node.js

## Funcionalidades
- Almacenar las ventas en un arreglo de objetos.
- Consultar la información de las ventas.
- Mostrar los registros en una tabla.

## Cómo ejecutar
1. Abrir el proyecto en VS Code.
2. Abrir la terminal.
3. Ejecutar: node src/explorar.js
